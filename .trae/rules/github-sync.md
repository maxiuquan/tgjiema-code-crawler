# GitHub 同步配置

## 远程仓库
- **地址**: https://github.com/maxiuquan/tgjiema-code-crawler.git
- **用户名**: maxiuquan
- **分支**: main

## Git 配置
```bash
git config --global user.name "maxiuquan"
git config --global user.email "maxiuquan@users.noreply.github.com"
```

## Token 认证
GitHub Token 已保存到系统 keyring，通过 `gh auth` 管理。
如需查看当前认证状态：`gh auth status`

## 常用命令
```bash
# 查看状态
git status

# 提交更改
git add .
git commit -m "描述你的修改"

# 推送到 GitHub
git push

# 拉取最新代码
git pull
```
