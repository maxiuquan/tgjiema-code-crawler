## 通用偏好

### Git 操作
- **自动提交**: 是

- **提交消息**: 使用简洁的中文描述本次修改内容
- **分支**: main
- **仓库**: https://github.com/maxiuquan/tgjiema-code-crawler.git

## 项目特定信息

### tgjiema-code-crawler 项目
- 这是一个 Telegram 文件码爬虫项目
- 用户手动加入频道后，系统只读取已加入频道的文件码，不自动搜索和加入新频道
- 主要功能：读取文件码 → 解码 → 同步到数据库
