📡 tgjiema-code-crawler（爬虫）
① 🕷️ crawler.py
爬取已加入 Telegram 频道中的消息
调用 code_extractor 提取文件码
• 获取已加入频道列表
• 遍历消息（limit=200/频道）
• 并发爬取（信号量控制）
② 🔍 code_extractor.py
正则提取 bot:code 格式文件码
支持多种书写格式
• bot:code / bot_code / bot code
• 紧邻附加 / 无头码关联
• 返回 (code, bot, 置信度)
③ 💾 storage.py（SQLite）
本地 SQLite 存储 codes.db
file_codes 表存放发现的文件码
• 缓存待解析码
• 跟踪解析状态/重试次数
• 支持导出 JSON/CSV
④ 🔄 resolver.py
向外部 Telegram Bot 发送码
收集返回的文件 → 复制到存储频道
• 事件驱动（NewMessage 监听）
• 支持翻页（自动检测+点击）
• settle 等待机制
• 限速检测与处理
⑤ 📤 cockroach_sync.py
将解析结果同步到 CockroachDB
写入 file_records & code_bot_mapping
• 基础码同步（未导出记录）
• 已解析记录同步（storage 位置）
🔗 联动核心
共享 CockroachDB
爬虫写入 → file_records
主程序查询 → 发送文件给用户
写入 code_bot_mapping
共享存储频道
upload_bot → 用户上传文件
resolver → 解析外部文件
user_relay → 中继缓存文件
sender_bot → 读取并发送
外部码两种路径
路径A(爬虫): 批量爬→解析→存DB
路径B(中继): 用户请求→中继代发→实时缓存
殊途同归 → sender_bot 发送
